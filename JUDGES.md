# For judges: each claim, its code, its test, the command, the expected output

Everything here is free and needs no keys. `npm run judge` (about a minute on a 2-CPU Linux box,
no Rust) runs row 0 and rows 17b and 18 and ends in a pass/fail table. `npm run judge:full` adds
every row marked * (the contract's Rust unit tests and the attack table, which need rustup and
about three minutes to build near-sdk's test runtime) and † (the long suites). The rest name their
own command. Test names are in `contracts/ghost-duels/src/tests.rs` unless noted.
